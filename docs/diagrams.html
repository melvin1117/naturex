🌿 NatureX — AI rating agency & exchange for living nature

Nebius × NVIDIA Global AI Hackathon · Track: Best Apps & Agents · Nemotron on Nebius Token Factory + Tavily

“The bees never sent an invoice.”

Nature works for free, so markets value it only once it’s destroyed.

WildWorth uses AI to measure what a living forest or wetland is worth every year, turns it into a rated asset people can invest in, and monitors it from space, so keeping nature alive pays more than destroying it.

The problem

🌳

Only dead nature has a price

Timber and land are priced; clean water, flood protection and carbon storage (~$100T/yr) are not.

🏭

Communities can only sell

A village next to a factory zone can sell its wetland once, but can’t earn from keeping it alive.

💼

Investors can’t trust the data

Money is earmarked for nature, but valuations are slow, costly and hard to verify.

The heart of WildWorth

The AI Rating Engine: from satellite pixels to a graded Ecological Performance Report

For any piece of land it answers three questions: How healthy is it? What is it worth each year? How sure are we? Numbers come from transparent, tested formulas. NVIDIA Nemotron agents gather the evidence, cross-check it, and explain the result.

3 · Health Score: five parameters

ParameterWhat it tells usData sourceHow it’s calculated (0 → 1)Weight
🌿 Vegetation vigor (V)Is the vegetation green, dense and improving?Sentinel-2 NDVI, monthly, 5 yrsV = ½·clamp(0.5 + trend/0.02) + ½·clamp(meanNDVI/0.8)30%
🌳 Natural cover (N)How much of the land is still natural?Dynamic World land cover (10 m)N = share of trees + water + flooded veg. + grass + shrub25%
🪓 Habitat integrity (L)Has habitat been cleared recently?Hansen Global Forest ChangeL = 1 − clamp(loss_ha_5yr / (10% of area))20%
💧 Water stability (W)Is surface water shrinking or stable? (wetlands)JRC Global Surface WaterW = clamp(0.5 + water_change%/100); W = 1 if not a wetland15%
⚠️ Threat pressure (T)Are there active threats nearby?Tavily news, classified by Nemotron NanoT = 1 − clamp(Σ severity of negative events / 15)10%
Health = 100 × (0.30·V + 0.25·N + 0.20·L + 0.15·W + 0.10·T) + Auditor adjustment (−10 … +10, must be justified with evidence) Grade: AAA ≥ 90 · AA ≥ 80 · A ≥ 70 · BBB ≥ 60 · BB ≥ 50 · B ≥ 40 · C ≥ 30 · D < 30

5 · Confidence: how sure are we?

Confidence = 100 × ( 0.4·coverage + 0.3·agreement + 0.2·evidence + 0.1·recency )
FactorMeaningScoring
CoverageEnough cloud-free satellite images?min(cloud-free scenes / 24, 1)
AgreementDo satellite data and news tell the same story?0–1, judged by the Auditor
EvidenceVerified community photos on the ground?1 if verified, else 0.3
RecencyIs the data fresh?1 if < 90 days old, else 0.5

An asset can only be listed if confidence ≥ 70%, grade ≥ C and habitat loss in the last 12 months is below 1% of the area.

6 · Where the AI (Nemotron) fits and where it doesn’t

🤖 AI does

  • Plans the rating run and calls tools (Nemotron 3 Super)
  • Classifies news: relevance, impact type, +/− direction, severity 1–5 (Nemotron Nano)
  • Reads photos: species, water clarity, signs of damage (MiniCPM-V sees, Nemotron Ultra judges; GPS/date checked in code)
  • Audits: cross-checks all evidence, flags greenwashing, adjusts score within ±10, writes the report (Nemotron 3 Ultra)

🛡️ Guardrails

  • All numbers come from deterministic, unit-tested code, never invented by the LLM
  • Every claim must cite a metric or news source ID
  • Outputs validated against a JSON schema; web content treated as untrusted
  • Evaluated with make eval: news accuracy, faithfulness, schema pass rate

5 · How a listing is verified (no black box)

✍️ Self-attested→ 📄 Documents submitted (or 🧪 sample docs in demo)→ 🔎 Checklist runs→ 🧑‍⚖️ Reviewer decides→ 🔗 Ledger + public panel
📄 Title or agrarian certificate, assembly minutes (consent), community registration
🔎 Each check shows pass / warn / fail and what it found: accepted file format, not reused, no boundary overlap, consent-labelled document attached; optionally an AI heuristic compares name, place and area with the listing (it only suggests, and the reviewer sees the source)
🧑‍⚖️ An admin approves or rejects with a reason (in demo mode, sample documents are auto-approved only if all checks pass and nothing was revoked); in the live world the IPO needs “verified”; changing the land or documents resets it; revoking suspends trading
🔗 The ledger records the decision, the reviewer role and private document commitments (never the documents or names); investors see “How this listing was verified”, including what was not checked

Hackathon

Documents + visible checklist + admin decision (+ an AI consistency hint if time allows). The badge says “Documents reviewed by WildWorth (hackathon process)”, never “ownership proven”.

🧪

Demo mode (deployment, judges, E2E)

Nobody has real land papers in a demo, so “Use sample documents (demo)” generates fictional, watermarked papers (listing reference, place and area only; no user-written text). The real checklist runs; a demo auto-reviewer approves only sample documents, only if every check passes, and never after a revoke. Sample runs say “Demo verification: sample documents, no real ownership checked” (badge, panel, ledger, footer). Real launch: VERIFICATION_MODE=review; demo approvals stop counting.

🏛️

Real world (same model, more checks)

Land-registry match (in Mexico: RAN for communal and ejido land, the public property registry for private land) · legal entity · community consent (FPIC) · accredited local verifiers · 30-day public objection period · yearly re-verification and disputes.
